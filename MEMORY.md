- Data (downloaded 2026-09-10, see code/fetch/fetch_data.sh for URLs), all under /data/LyaLenser/raw/:
  - desi/lya-deltas/delta-lya-0-0/Delta/delta-*.fits.gz: DR1 Lya deltas VAC v1.0 (1028 HEALPix files, 5.8 GB). Format: HDU LAMBDA (linear grid, 0.8 A, 3600-5772 A), METADATA (LOS_ID, RA, DEC in radians, Z, MEANSNR, TARGETID), DELTA_BLIND (nforest x nlambda), WEIGHT, CONT. Rest-frame 1040-1205 A, >=150 pixels, DLA/BAL masked. The extension is named DELTA_BLIND with BLINDING=desi_y1, but in picca the desi_y1 strategy blinds only the fiducial redshift-distance conversion inside picca_cf (constants.Cosmo(blinding=...)); the delta arrays themselves are the measured fluctuations, and picca_export lists desi_y1 as unblindable. We use our own chi(z), so no blinding applies. Log/delta_attributes.fits.gz has the continuum-fitting attributes.
  - desi/qso_iron/QSO_cat_iron_cumulative_v0.fits: DR1 QSO redshift catalogue (816 MB). desi/lss_v1.5/: QSO clustering catalogues (NGC/SGC), n(z), and randoms 0-3 per cap (~1.3 GB NGC / 0.74 GB SGC each).
  - act/dr6_lensing_release.tar.gz (LAMBDA, 1.37 GB, all 13 variants) and act/baseline/ (kappa alm, mask nside 4096, N_L, filter, README from the NERSC mirror https://portal.nersc.gov/project/act/dr6_lensing_v1/); act/baseline/simulations/: 400 sim alms x 153 MB (61 GB) from the same mirror.
  - planck/PR4_variations/: Carron+2022 "2018-like" PR4 lensing: PR42018like_klm_{dat,mf}_{MV,TT,PP}.fits (lmax 2048), mask.fits.gz (nside 2048, fsky 0.67). No N_L file and no sims in the public tar (sims + PR4_nlkk_p.dat are NERSC-only at $CFS/cmb/data/planck2020/PR4_lensing/).
