# Stage A iteration 3: prospective acceptance protocol

Written before any fresh validation seed is generated by the iteration-3 code.
No git commit is made, as explicitly requested. The runner records this file's
SHA256, the source SHA256s, development results, and UTC launch time before
starting validation. This file and the frozen configuration are copied to the
large-product directory. A changed source/configuration invalidates a resumed run.

## Ensemble and numerical freeze

Development uses **only seeds 100–104**, at scale 1, to choose the measured-xi
Gaussian smoothing width from {0.76, 0.9, 1.1, 1.3, 1.5, 1.7, 2.0} one-Mpc/h bins. The prospective
choice rule is minimum deviation of the mean physical slope from unity. The
choice and development amplitude-grid convergence measurements are saved in
`/data/LyaLenser/mocks/iteration3/development.json` and `frozen.json` before the
validation launch. If a numerical gate fails, it remains FAIL; validation
results will not be used to change the choice.

Fixed numerical settings: xi step 0.25 Mpc/h, coarse counts 1 Mpc/h, cubic
spline after normalized Gaussian smoothing, analytic nk=6400 and kmax=35,
float64 accumulation, float32 catalogue storage, 24 Numba threads, four FFT
workers, scale=1 (20-degree patch), 2×2×0.5 Mpc/h density cells, 0.55 Mpc/h
forest pixels, science bands [40,100], [100,200], [200,300] with 10-L cosine
tapers. Junk is **1 minus the sum of science windows**, through the diagonal
FFT Nyquist. Each fit contains all three science bands, their curls, and junk.
Singular full responses are errors; unavailable leave-region fits have NaN
errors and cannot qualify as passing evidence.

The empirical 0.903 forest factor is removed. Measured xi carries the
normalization. Analytic-versus-observed normalization is still tested and is
not assumed equivalent. The physical light cone uses spherical unit rays in
a Cartesian box. Local east/north shifts use cos(dec), and the unchanged pair
kernel uses cos(dec_mid). The flat FFT map operator remains a flat-patch
approximation; acceptance measures its residual. All density realizations
have a fixed 300 Mpc/h radial margin; matched selections use 150 Mpc/h unless
explicitly varied. Both convergence projections and catalogue intensities are
sampled along the same rays as the forests.

CMB, matched, and deprojected maps use a common 128×128 angular grid and mask.
The CMB map is Fourier resampled; matched counts use the same pixels. The
common mask is the ACT cutout times the matched completeness/random-count
mask. CXX is measured from each actual masked noisy map in fixed width-40
multipole annuli, divided by mean(mask²). S uses the actual template radial
range, catalogue density, and magnification coefficient, the count-pixel
window, and the same mask convolution. Random templates receive that same
mask and saved CMB transfer. The independently predicted response propagates
pixel modulation through weighted continuum projectors; its raw covariance is computed from the mock discrete Fourier grid, with
128 transverse-angle samples and the exact phase-averaged trilinear window:
C_interp(r)=sum_n C_grid[n] product_i B3(r_i/d_i−n_i), where B3 is the
autocorrelation of the linear interpolation hat and
C_grid=IFFT[P_F(k)/cell_volume]. This includes aliases without a fitted factor.
The table has 40 Mpc/h support. Transverse-angle averaging and radial
truncation remain approximations; their errors are not assigned a zero
deprojected prediction.

Recovery: seeds **0–19**. Nulls: seeds **20–39**. No other seeds may be added
because of a mean-field significance or a normalization failure. After all
40 finish, if either absolute deprojected response-only null or absolute
combined recovery has a 95% residual bound greater than 0.3 A, run **all
seeds 40–59 once**. Those twenty extension realizations contribute to both
recovery and null ensembles. No intermediate stopping. No extension beyond
59. If the resulting bound remains above 0.3 A the gate is FAIL.

The fixed-template conditional test uses the **same development seed-100
maps and operators on every null seed**, sampled at that seed's positions.
Raw and corrected means always use exactly the same seeds. Missing products,
nonfinite values, or an unexecuted required check are FAIL, never PASS.

## Statistics and gates

All amplitudes are absolute `F^{-1}(q-mf)`, where mf is that sample's own
prescribed baseline subtraction. Fit summaries and per-region q, F, mf are
persisted. Paired differences may appear only as **diagnostic** comparisons.
Every ensemble amplitude or slope reports its mean, SEM (sample standard
deviation / sqrt(N)), and the achieved two-sided 95% residual bound
`abs(mean-target) + t_{N-1,0.975} SEM`. Bounds are in A units for amplitude
rows and slope units for slope rows. No small-S/N consistency alone is used
as evidence of normalization precision.

| Gate | Acceptance requirement |
|---|---|
| Tests | All existing algebra/physical tests and new regression tests pass. Incompatible old zero-junk/orthogonality fixtures are corrected, with their original algebra assertions retained. |
| xi interpolation | On the same sample, halving 0.25 to 0.125 changes absolute common science A by <0.5%. Also tested through a small synthetic compression/fit. |
| Analytic derivative | Doubling nk=6400 changes derivative array norm over 10≤r_perp≤30, 0≤r_parallel≤30 by <1%. |
| Discrete-grid covariance quadrature | Before validation, 128→256 transverse-angle samples change the derivative norm over 10≤r_perp≤30 by <1%; grid shape comes from development seed 100. |
| Truth normalization | Absolute fitted slopes at A_true={0,1,5,10}, response off, sparse noisy mocks: abs(mean slope−1)≤0.03. Report SEM and bound. |
| Filtered CMB normalization | Same slope gate, scaling only kappa_lya in the physical remapping. |
| Matched normalization | Same slope gate, scaling only kappa_lya in the physical remapping. |
| Fixed versus refitted baseline | Absolute slope difference ≤0.03; also report fixed-minus-refitted A at A_true=1 with SEM. Each relevant observed sample gets its own xi table. |
| Data versus analytic baseline | Dense scale-1 noiseless normalization slopes agree within 3%. |
| Dense physical normalization | Scale-1, n_los=100/deg², P_N=0, A_true={0,1,5,10}; both g-on/moments-on and g-off/moments-off slopes within 0.05 of 1. One fresh seed (0) per variant. Report slope regression error; it is not an ensemble SEM. |
| First moments | Ratio of omitted-moment to correct-moment slopes agrees with the catalogue contraction prediction within 5%. |
| Varying-template mean fields | Truth, CMB, matched absolute A_true=0 response-off means each within 2 SEM of 0. Raw means on identical seeds reported. |
| Fixed-template mean fields | Same criterion, using fixed development seed-100 template maps/operators on all null seeds. |
| Absolute stochastic recovery | CMB A_true=1 response-off within 2 SEM of 1; the independent slope gate supplies the normalization precision requirement. |
| Response-only CMB/matched | Absolute estimate minus independent pixel-level prediction within 2 SEM of 0; each observed/predicted/difference statistic has SEM and bound. |
| Response-only deprojected | Independent prediction agreement within 2 SEM AND absolute null bound95≤0.3 A. |
| Combined deprojected recovery | Absolute response-on A_true=1 within 2 SEM of 1 AND residual bound95≤0.3 A. |
| Shape | Six absolute amplitudes, five contrasts, full sample covariance; Gaussian Hotelling F-test p>0.01. |
| Covariance | Scatter of absolute combined A / RMS per-mock midpoint jackknife error in [0.7,1.3]. |
| Spectra | Mean total klkl, klkc, kckc measured/theory ratios each within 10%; outside-box draws retain the verified restricted Limber implementation. |
| Injection bookkeeping | Full seven-component fit to ±1,±2 and 0 coordinate injections; common science odd slope in [0.95,1.05], curl slope within its jackknife error. This is not physical calibration. |
| Flag/margin diagnostics | Absolute A shifts for magnification off, completeness off, ACT mask off; margins 0,150,300 varied using one fixed larger correlated realization, unchanged sightlines and CMB. All products persisted; report only, no numerical tolerance. |
| Random-template diagnostic | 100 independent identically masked Gaussian CMB templates; absolute amplitude scatter, SEM, bound, scatter/jackknife and scatter/sigma_F reported; no numerical tolerance. |
| Benchmark, provenance, memory | 24 Numba threads; finite positive pair throughput; peak RSS <40 GB; tables/operators/partial sums and per-seed diagnostics persisted. |

A single failed required gate blocks Stage B. The report will explicitly
retain failures and their diagnoses rather than relabeling an imprecise result
as a pass.
